# ServiceDesk Intelligence

منصّة تحليلات وذكاء اصطناعي فوق نظام الدعم الفني **ManageEngine ServiceDesk Plus**
(on-premise, API v3) — من السحب الآمن للبيانات، إلى تحليلها، إلى نماذج تعلّم آلي
تشغيلية بلغتين (عربي/إنجليزي).

النظام يحوّل بيانات الدعم الخام إلى قرارات: توجيه التذاكر تلقائيًا، رصد الأعطال
المتكررة, توقّع أحجام الطلبات، وتشخيص أسباب خرق مستوى الخدمة (SLA) — كلّها مبنية
على بيانات فعلية ومقيَّمة بمنهجية صارمة قبل أي اعتماد.

```
~7K تذكرة   ·   مئات طلبات التغيير   ·   قاعدة معرفة   ·   مشاريع   ·   مشاكل
```

---

## لماذا هذا المشروع

| المبدأ | كيف يُطبَّق |
|--------|-----------|
| **آمن على الإنتاج** | كل الاتصال بالـ API قراءة فقط (GET) — صفر إنشاء/تعديل/حذف على السيرفر |
| **يحترم الخصوصية** | إخفاء هوية كامل (أسماء→رموز، حذف الجوالات، تعقيم النصوص) قبل خروج أي بيانات من الجهاز |
| **مقاوم للانقطاع** | السحب idempotent مع استئناف تلقائي وbackoff عند حظر السيرفر المؤقت |
| **قرارات مبنية على أدلة** | كل نموذج يُقيَّم بتقسيم زمني قبل الاعتماد؛ النتائج السلبية تُوثَّق ولا تُخفى |
| **قابل لإعادة الإنتاج** | كل تقييم وتقرير يُشغَّل بأمر واحد |

## القدرات

### 📊 خط بيانات كامل
سحب مقاوم للانقطاع لكل وحدات النظام (requests, problems, changes, projects,
solutions/KB + الجداول المرجعية)، مع تسطيح الـ JSON المتداخل، معالجة التواريخ،
تنظيف نصوص HTML، وكشف لغة كل تذكرة (عربي/إنجليزي/مختلط) — وإصدار مُخفى الهوية
لكل جدول.

### 🤖 نماذج التعلّم الآلي

| التطبيق | المقياس | الحالة |
|---------|---------|--------|
| **توجيه التذاكر تلقائيًا** للفريق المناسب من النص | دقّة **87%** (تقييم زمني، Macro-F1) | ✅ جاهز |
| **رصد الأعطال المتكررة** — تجميع نصّي متعدّد اللغات (HDBSCAN) | تقرير شهري بأكثر المشاكل تكرارًا | ✅ جاهز |
| **توقّع حجم الطلبات** — تنبؤ زمني لكل فريق (Prophet) | مقارَن بخط أساس ساذج | ✅ جاهز |
| **البحث الدلالي عن الحلول** — استرجاع أقرب الحلول السابقة | recall@5 = 24–26% → **قرار لا-قو موثّق** | ⏸️ معلّق (بيانات) |

> **شفافية منهجية:** البحث الدلالي أُوقف قبل بناء أي واجهة بناءً على تقييم صارم
> (50 تذكرة محجوبة الحل، قياس recall@k). المسترجِع يعمل، لكن 76% من حقول الحل
> مجرّد "Done/تم" بلا محتوى قابل لإعادة الاستخدام — فالمعالجة **تنظيمية** (قالب
> إغلاق يُلزم بتوثيق الحل)، لا خوارزمية. التقييم قابل لإعادة التشغيل، ونعيد
> القياس فور تحسّن التوثيق.

### 📈 لوحة معلومات تفاعلية
داشبورد Streamlit بتصميم مؤسسي (فاتح/داكن) — مؤشرات تشغيلية، توزيعات حسب
الخدمة/الفريق/الفني/الحالة/الموقع/اللغة، فلاتر، وتصدير CSV. أي قيمة من نموذج
تُعرض معلّمة بمصدرها ودرجة ثقتها؛ الرسوم تعرض قيم النظام الفعلية فقط.

## أبرز المؤشرات (من التحليل الفعلي)

- **خرق SLA:** نحو 12% من التذاكر
- **التركّز:** فريق واحد يحمل الأغلبية العظمى من الحِمل
- **جودة البيانات:** حقل الأولوية فارغ في معظم التذاكر — قابل للمعالجة بالنمذجة
- **جاهزية النص:** كشف لغة موثوق يمكّن النمذجة ثنائية اللغة

## الهيكل

```
pipeline/    sdp_client · extract · preprocess · anonymize · refresh
models/      routing/ · clustering/ · forecasting/ · similar · features · embeddings
insights/    eda · dashboard · ml_tab  (+ التقارير الناتجة)
config/      settings.py (يقرأ .env)
data/raw/    JSON خام            (git-ignored)
data/processed/  جداول CSV/Parquet جاهزة للـ ML (+ نسخ *_anon)   (git-ignored)
```

> 🔒 البيانات تحوي معلومات شخصية. `data/` و `.env` والـ JSON الخام كلها git-ignored.
> أي مخرَج يغادر الجهاز يجب أن يكون النسخة `*_anon`.

## التشغيل

**1) السحب** (يحتاج وصولًا للسيرفر — GET فقط، idempotent)

```bash
python -m pipeline.extract --modules requests,problems --limit 20 --skip-details  # فحص سريع
python -m pipeline.extract                                                        # سحب كامل
```

**2) التجهيز**

```bash
python -m pipeline.preprocess --anonymize      # جداول جاهزة + نسخ *_anon
```

**3) التحليل الاستكشافي**

```bash
python -m insights.eda                          # eda_summary.md + رسومات
```

**4) النماذج**

```bash
python -m models.routing.train --evaluate       # تقييم زمني لتوجيه الفريق
python -m models.routing.train --build          # بناء النموذج النهائي
python -m models.clustering.recurring --build   # تقرير الأعطال المتكررة
python -m models.forecasting.forecast --build   # توقّع 4 أسابيع لكل فريق
python -m models.similar --evaluate             # بروتوكول recall@k (البحث الدلالي)
```

**5) الداشبورد**

```bash
streamlit run insights/dashboard.py
```

**تحديث شامل بضغطة واحدة** (سحب → تجهيز → توقّع):

```bash
python -m pipeline.refresh
```

## ملاحظات تشغيلية

- كل نموذج يُقيَّم بتقسيم **زمني** (تدريب على الأقدم، اختبار على الأحدث) لمحاكاة
  الإنتاج ومنع التسريب الزمني.
- تقارير النماذج تستخدم معرّفات مجهولة للفنيين؛ التحليل مطبَّع حسب الحِمل ونوع
  التذاكر — أداة لتحسين النظام لا لتقييم الأفراد.
- `truststore` يتيح تنزيل نماذج HuggingFace عبر بروكسي فحص TLS المؤسسي.
